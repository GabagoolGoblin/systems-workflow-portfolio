# Claims and boundaries

## Supported

- Implemented deterministic claim-to-evidence contract evaluation in standard-library Python.
- Bound citations to exact Unicode spans, typed assertions, controlled fact IDs, risk-tier rules, and source digests.
- Added strict validation, safe local writes, stable verdict reason codes, and exact report rebuild verification.
- Verified the frozen source with 52 unit tests plus audit and tamper demonstrations.

## Not supported

- Truth verification, fact checking, semantic entailment, source-quality scoring, or proof that sources are independent.
- Model inference, autonomous research, production governance, regulatory compliance, or customer deployment.
- Author identity, non-repudiation, trusted timestamping, or an immutable ledger.

The safe description is a deterministic control over declared evidence metadata—not a truth engine.
