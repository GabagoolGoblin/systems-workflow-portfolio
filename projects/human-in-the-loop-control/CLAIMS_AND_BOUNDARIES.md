# Claims and boundaries

> INDEPENDENT PORTFOLIO DEMO · SYNTHETIC DATA · NO AFFILIATION · NO PRODUCTION ACTION

## Supported claims

- The checked-in code implements cache lookup, unknown holds, manual validation, staging, reread verification, mismatch blocking, and explicit human approval.
- Headless tests exercise both successful and fail-closed paths.
- The optional GUI smoke writes only to an injected temporary or explicit external path; the tracked tree is not a log destination.
- The code-native browser preview is a fresh public presentation of the same bounded state-machine concepts.

## Unsupported claims

- No employer, customer, vendor, or production workflow is represented.
- No live UI automation, external write, durable save, integration, deployment, performance result, or operational authorization.
- No claim that a visual is a product screenshot or that the demo replicates any existing system.
- No complete security, accessibility, or reliability assessment.

Human approval changes only invented in-memory values after the demo's checks pass.
