# Claims and boundaries

## Supported

- Designed and implemented an original static workflow for catalog lifecycle review.
- Modeled scope visibility, before/after comparison, explicit unknown holds, human decisions, and an audit presentation.
- Built the interface with plain HTML, CSS, JavaScript, and standard-library tests.
- Verified the frozen source with twelve deterministic project-contract tests.

## Not supported

- A live catalog integration, deployed automation, employer/customer system, or proprietary product capability.
- Durable workflow state, authenticated approval, cryptographic audit, production write, or operational scale.
- WCAG conformance, assistive-technology behavior, legal certification, or a comprehensive accessibility audit.

Every portfolio description should preserve the synthetic, offline, no-production-action boundary.
