# Capability demo script

> INDEPENDENT PORTFOLIO DEMO · SYNTHETIC DATA · NO AFFILIATION · NO PRODUCTION ACTION

## 90-second path

**0:00–0:15 — Readiness board**

“This is a clean-room, offline implementation workflow using an entirely fictional baseline. I designed it to answer three questions quickly: what is known, what is blocked, and who owns the next move. The status labels are operational; they never claim compliance.”

Point to the permanent disclosure, the four summary cards, and the control implementation board.

**0:15–0:35 — Gap triage**

Open **Gap triage** and select `GAP-07`.

“The gap keeps the missing fact exact: the synthetic roster exists, but its review period is not declared. Severity, owner, target, and the linked action stay together. The interface doesn't invent the missing value.”

Use the filters briefly, then click **Open owner action**.

**0:35–0:55 — Owner actions**

Find `ACT-204` and advance it twice.

“Completing the queued work changes the linked gap to review-ready. It does not silently accept the record. That separation is important when implementation work and customer review happen at different times.”

**0:55–1:15 — Acceptance desk**

Open **Acceptance desk**, choose `IR-01`, and run the checks.

“The rule set is visible: named owner, mapped records, locators, conflict state, blocking gaps, completed actions, and reviewer acknowledgment. The last gate stays stopped until a person records the synthetic acknowledgment.”

Click **Record reviewer acknowledgment**.

“Now seven of seven local prerequisites pass. The label is carefully scoped: locally ready, not compliant or certified.”

**1:15–1:30 — Audit trail**

Open **Audit trail**.

“Every simulated transition and acceptance event becomes reviewable. The JSON button creates a local receipt only; there is no service, account, API, or upload behind this demo.”

## If asked what is real

- Real: the interface, responsive layout, state machine, filtering, source qualification, acceptance logic, audit event generation, local export, deterministic tests, and screenshot pipeline.
- Synthetic: every organization, framework label, control, record, person, timestamp, identifier, action, and result.
- Not represented: vendor product behavior, a live integration, professional assessment, certification, legal guidance, or production deployment.

## Useful implementation questions

**Why does action completion not close the gap?**  
Because completing a task and accepting its outcome are distinct decisions. The demo moves the gap to review-ready and requires a separate acceptance run plus reviewer acknowledgment.

**Why embed the data?**  
The artifact is designed for safe, repeatable portfolio review. Embedded fixtures remove credentials, services, customer data, and network dependencies while preserving the workflow behavior.

**What would change in production?**  
Authentication, authorization, durable storage, concurrency controls, integrations, schema validation, error recovery, telemetry, professional framework content, and formal accessibility/security testing would all require production design and review.
