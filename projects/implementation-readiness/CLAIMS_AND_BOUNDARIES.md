# Claims and boundaries

> INDEPENDENT PORTFOLIO DEMO · SYNTHETIC DATA · NO AFFILIATION · NO PRODUCTION ACTION

## Supported claims

- The checked-in code implements evidence qualification, gap ownership, review-state transitions, seven visible acceptance checks, in-memory audit events, and a user-triggered local receipt.
- The bundled tests inspect the state-machine contracts, HTML escaping, offline boundary, semantic shell, and persistent disclosure.
- The runtime uses no account, credential, server, customer record, remote asset, or automatic network request.

## Unsupported claims

- No compliance, certification, legal, security, or professional-assessment conclusion.
- No production deployment, customer outcome, live integration, durable audit, or authorization to act.
- No claim about any vendor's product, interface, implementation method, requirements, or internal workflow.
- No accessibility or security certification; the checks are bounded portfolio evidence.

Every runtime state is a fictional operational label. A human acknowledgement changes only in-memory demo state and never establishes external acceptance.
