# Claims and boundaries

## Supported

- Implemented an original offline API/webhook contract lab in standard-library Python and static browser code.
- Exercised strict request/response checks, HMAC fixture verification, replay/idempotency ordering, virtual retry, schema quarantine, a human gate, and deterministic receipts.
- Added adverse-input, tamper, project-contract, security/privacy, and real-browser verification.
- Verified this project with 48 tests, 31 focused scan checks, and 12 browser checks.

## Not supported

- Paid production integration experience, a live vendor/customer endpoint, traffic, uptime, throughput, or deployment.
- A secret credential, authenticated reviewer, authorized promotion, durable idempotency, production observability, compliance validation, or penetration testing.
- An immutable/signed audit record or affiliation with any employer or product company.

The artifact makes integration reasoning inspectable; it is not evidence that this exact system operated in production.
