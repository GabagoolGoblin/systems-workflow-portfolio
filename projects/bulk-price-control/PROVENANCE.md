# Provenance

This clean-room project contains original standard-library Python and invented catalog/CSV fixtures. No employer export, customer menu, transaction, production identifier, vendor schema, proprietary client, or private operating procedure is represented.

The tool reads and writes only paths supplied by its local caller. It contains no network adapter, credential support, remote asset, telemetry, or implicit confirmation path. Test mutations occur only in temporary directories.

The root `LICENSE` governs cleared owner-created material. Local outputs under `out/` remain untracked and may contain caller-provided data; they are outside the release inventory.
