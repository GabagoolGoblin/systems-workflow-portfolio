# Claims and boundaries

## Supported

- Implemented a deterministic, non-rendering HTML fixture regression harness.
- Documented and tested nine bounded accessibility-oriented contracts.
- Added fail-closed parsing, exact expected fingerprints, reproducible reports, and a SHA-256 evidence chain.
- Verified the frozen source with 41 unit tests and exact audit verification.

## Not supported

- Full WCAG conformance or coverage of any WCAG success criterion.
- Browser layout, CSS behavior, accessible-name computation, keyboard behavior, screen-reader output, or assistive-technology interoperability.
- Legal certification, compliance determination, security signature, trusted timestamp, or evidence authorship.

The rule identifiers intentionally avoid success-criterion numbers. The README lists the bounded rule families; source modules and tests define their exact algorithms and blind spots.
