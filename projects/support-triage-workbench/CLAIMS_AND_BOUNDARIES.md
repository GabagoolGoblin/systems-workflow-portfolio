# Claims and boundaries

> INDEPENDENT PORTFOLIO DEMO · SYNTHETIC SUPPORT RECORDS · NO AFFILIATION · NO SEND ACTION

## Supported claims

- The source implements strict schema validation, deterministic routing, duplicate holds, redaction, evidence-backed outlines, explicit approval, and hash-linked local audit verification.
- The tests exercise schema attacks, held states, redaction, routing, approval, tamper detection, and CLI JSON output.
- No network or message-sending module is part of the runtime.

## Unsupported claims

- No production deployment, live integration, response-time improvement, resolution-rate result, customer use, or authority to communicate.
- No claim that a locally approved outline was sent or that an issue was resolved.
- No claim that the demo routing rules represent any organization's policy.
- No complete privacy, security, or compliance assessment.

Approval is an explicit local operator action and cannot override a hold. Corrected input must produce a new result.
